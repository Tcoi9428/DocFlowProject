# DocFlow Prototype

Прототип внутреннего веб-сервиса документооборота на Django.

## Что уже реализовано

- 5 типов документов:
  - договоры;
  - служебные записки;
  - приказы;
  - внутренние документы, инструкции, методики, положения;
  - счета/УПД и заявки на оплату.
- Автоматическая системная нумерация по типу документа и году.
- Поле для внутреннего номера компании.
- Базовая карточка регистрации документа.
- Пользовательские поля по типам документов через админку.
- Вложения до 20 МБ. Файлы хранятся на диске, в базе хранится путь и hash.
- Последовательные и параллельные маршруты согласования.
- Возврат на доработку, отклонение, согласование, делегирование.
- Сроки согласования и отчет по просроченным задачам.
- Журнал действий пользователя.
- Стандартная авторизация Django: логин/пароль.
- Админка для справочников, пользователей, групп и прав.

## Как устроен проект

```text
docflow_project/       настройки Django
documents/             основное приложение документооборота
documents/models.py    структура таблиц базы данных
documents/forms.py     формы создания и редактирования
documents/views.py     логика экранов
documents/services.py  бизнес-логика согласования
templates/             HTML-шаблоны
static/css/app.css     стили интерфейса
media/                 загруженные файлы документов
```

## Как проверить процесс согласования

1. Войти как `user / user`.
2. Создать документ.
3. Выбрать тип документа.
4. Заполнить реквизиты и сохранить.
5. Загрузить вложение при необходимости.
6. Нажать "Отправить на согласование".
7. Выйти и войти как `manager / manager`.
8. Открыть "На согласовании".
9. Согласовать документ.
10. Если маршрут требует директора, войти как `director / director` и согласовать следующий этап.

## Нумерация документов

Формат системного номера:

```text

```

Примеры:

```text
DOG-2026-00001
SZ-2026-00001
PRK-2026-00001
VND-2026-00001
PAY-2026-00001
```

## Переход на Microsoft SQL Server 2019

Сейчас прототип работает на SQLite, чтобы быстро проверить интерфейс и логику.

Для SQL Server нужно:

1. Создать новую базу данных, например `DocFlow`.
2. Установить ODBC Driver for SQL Server на Windows Server.
3. Установить Python-пакеты:

```powershell
pip install mssql-django pyodbc
```

4. В `docflow_project/settings.py` заменить блок `DATABASES` на подготовленный блок для `mssql`.
5. Заполнить параметры подключения.
6. Выполнить:

```powershell
python manage.py migrate
python manage.py seed_demo
```

## Важное ограничение прототипа

Это рабочий MVP для локальной сети, но не промышленная публикация в интернет.

Перед внешним доступом нужно отдельно настроить:

- HTTPS-сертификат;
- production-сервер, например Waitress/IIS reverse proxy;
- надежный `SECRET_KEY`;
- `DEBUG = False`;
- список `ALLOWED_HOSTS`;
- резервное копирование базы и папки `media`;
- SMTP для реальных email-уведомлений;
- регламент прав доступа.
