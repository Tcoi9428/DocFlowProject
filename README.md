# DocFlowProject

Прототип внутреннего веб-сервиса документооборота для небольшой компании.

Проект сделан на Python Django. Сейчас это рабочий MVP для локальной сети: создание документов, маршруты согласования, вложения, уведомления, журнал действий, отчеты и базовая админка.

## Быстрый Запуск

Команды выполнять из папки проекта:

```powershell
cd C:\Users\i.petrikin\Documents\Codex\2026-05-26\c-codex
python manage.py migrate
python manage.py seed_demo
python manage.py runserver 127.0.0.1:8000
```

Открыть в браузере:

```text
http://127.0.0.1:8000/
```

## Тестовые Пользователи

## Что Реализовано

- 5 типов документов: договоры, служебные записки, приказы, внутренние документы, счета/УПД и заявки на оплату.
- Автоматическая системная нумерация по типу документа и году.
- Отдельное поле для внутреннего номера компании.
- Пользовательские поля по типам документов через админку.
- Вложения до 20 МБ: файлы хранятся на диске, в БД хранится путь и hash.
- Последовательные и параллельные маршруты согласования.
- Пользовательский выбор типа маршрута при создании документа. В параллельном маршруте замечания собираются независимо, а повторное согласование направляется только участникам, которые вернули документ.
- Пользовательская настройка маршрута при создании документа.
- Согласование, возврат на доработку, отклонение и делегирование.
- Внутренние уведомления в верхней панели и счетчик задач в боковом меню.
- Страница "На согласовании" с выбором документа слева и просмотром деталей справа.
- Журнал действий с отображением 10 последних записей и раскрытием остальных.
- Отображение пользователей в формате "Фамилия Имя Отчество" и должность из профиля.
- Отчеты по созданным документам, согласованиям, просрочкам, истории и архиву.
- Отдельный реестр корреспонденции с вкладками для входящих, исходящих писем и служебных записок.
- Регистрация исходящих писем с резервированием номера, формированием Word-бланка и контролем подписанного файла.
- Регистрация входящих писем с резервированием номера, файлами, резолюцией и связью с исходящим реестром.
- Поиск в личном и общем реестрах по номеру, наименованию, адресату или отправителю.

## Импорт исторической корреспонденции из Excel

Команда по умолчанию только проверяет файл и не изменяет базу данных:

```powershell
python manage.py import_correspondence_xlsx "C:\Полный\путь\2026.xlsx" --year 2026 --registrar USERNAME
```

После проверки отчета выполните импорт с флагом `--apply`:

```powershell
python manage.py import_correspondence_xlsx "C:\Полный\путь\2026.xlsx" --year 2026 --registrar USERNAME --apply
```

Повторный запуск для того же файла и строк не создает дубликаты. Перед импортом в рабочую
SQL Server необходимо сделать резервную копию базы данных.
