## Важные Договоренности По Проекту

- Не усложнять интерфейс без необходимости.
- Использовать Django Admin для справочников, пока отдельный интерфейс не требуется.
- Не удалять документы физически для обычных пользователей.
- Хранить файлы на диске, в БД хранить путь и hash.
- Пользователей отображать как `Фамилия Имя Отчество`, должность показывать под именем или в скобках.
- Для новых функций добавлять минимальные тесты, если меняется бизнес-логика.
